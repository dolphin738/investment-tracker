## 1. 产品目标与变更背景

### 1.1 变更背景

投资收益统计系统（`investment_return_tracker`）此前在持仓页【E】区块提供「分红 / 费用」独立录入与明细展示（HOLD-B-P0-10）。本次增量需求聚焦三件事：

1. **分红去融合**：此前尝试在「录入买卖」弹窗内加「买入/卖出 | 分红」Tab 融合录入，**用户明确不认可该交互**（编号 1），要求恢复原样。
2. **分红增强**：分红录入需要支持「所得税」字段；分红明细与累计展示口径调整为「净额」；分红记录需要支持编辑（当前只有新增+删除）。
3. **费用并入买卖**：费用从独立录入入口并入「录入买卖」弹窗，费用参与成本价计算（含费成本价），费用记录与买卖流水关联。
4. **统一 QA**：全部界面改动完成后统一 QA，含旧快照页 BUG-1/BUG-2 回归（只回归验证，不新修）。

### 1.2 撤销「分红融合」改动说明

### 1.3 产品目标

1. **口径正确**：分红「净额 = 税前金额 − 所得税」、买卖「含费成本价」作为全系统唯一口径，列表/汇总/成本推导保持一致。
2. **录入高效**：费用录入融入买卖流程（一次录入、费用随单），减少独立录入心智负担与重复操作。
3. **可追溯**：分红记录可编辑修正、费用记录通过 `transactionId` 与买卖流水关联，数据可回查。

## 2. 用户故事

- **US-1（分红所得税）**：作为投资者，我在录入分红时输入「分红额（税前）」和「所得税」，系统自动算出净额，这样我能准确记录实际到账金额，且不用自己心算。
- **US-2（累计分红口径）**：作为投资者，我希望「累计分红」按净额汇总，明细列展示「金额 / 所得税 / 净额」三列，这样汇总与明细口径一致、不会重复累加税前金额。
- **US-3（分红编辑）**：作为投资者，录错分红或税率后，我希望直接编辑该条分红记录（而非删除重录），这样能保留日期与备注等上下文。
- **US-4（费用并入买卖）**：作为投资者，我在录入买卖时一次性填写佣金 / 印花税 / 其他三笔费用，系统自动求和并折算进成本价，这样不必再单独去【E】区块录费用。
- **US-5（含费成本价）**：作为投资者，我希望系统按「成交额 + 费用」折算单价存入买卖记录，这样持仓成本与实付成本一致，卖出时的 XIRR 现金流口径自洽。

## 5. 关键口径（全局唯一，前后端必须一致）

| # | 口径 | 定义 |
|---|---|---|
| K-1 | **分红净额**（✅ 用户拍板） | `净额 = 分红额（税前）− 所得税`；**净额 ≥ 0**（所得税 ≤ 税前金额）。后端必须二次校验（防绕过前端）。`DividendRecord` 新增 `tax` 字段存储所得税（NUMERIC(18,2)，默认 0）；`amount` 语义 = **税前金额**（存量数据即税前，兼容）。 |
| K-2 | **累计分红口径**（✅ 用户拍板） | 汇总卡与按标的汇总 **按净额求和**（`Σ(amount − tax)`），不得累加税前金额。 |
| K-3 | **买卖含费成本价**（✅ 用户拍板） | 单价 = 含费成本价：<br>买入：`price = (成交额 + 费用合计) / 数量`<br>卖出：`price = (成交额 − 费用合计) / 数量`<br>计算结果存入 `trade.price`（NUMERIC(18,6)），`trade.fee` **恒为 0**。 |
| K-4 | **费用归属** | 买卖界面填写的费用**不写 `SecurityTrade.fee`**，按类型拆分为 `FeeRecord`（`type ∈ {COMMISSION, STAMP_TAX, OTHER}`），`FeeRecord.transactionId` = 关联的 `SecurityTrade.id`；前端保存顺序：先创建 Trade → 拿 id → 创建 3 条（或 ≤3 条，值为 0 的可跳过或写 0——实现细节由工程师定，业务口径为「有值的费用类型各落一条」）FeeRecord。 |
| K-5 | **费用合计** | `费用合计 = 佣金 + 印花税 + 其他`（≥ 0）；若卖出时费用合计 > 成交额，前端阻止提交（避免负单价），后端同样校验。 |
| K-6 | **缓存失效范围** | 分红/费用写入只失效 `['dividends']` / `['fees']` 自身缓存，**不触发** XIRR / 净值 / 持仓重算（延续 D-02 / D-03）。 |
| K-7 | **金额精度** | 金额/税/费用：NUMERIC(18,2)；单价：NUMERIC(18,6)。前端以字符串传输，避免浮点丢精。 |
| K-8 | **编辑口径** | 分红编辑 = 修改日期 / 标的 / 税前金额 / 所得税 / 备注；净额重算。 |
