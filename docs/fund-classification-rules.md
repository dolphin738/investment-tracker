# 证券自动分类规则（场内基金 / A股 / 可转债）

> 目标：仅凭「6 位证券代码 + 证券名称」自动判断一只证券的**资产大类**（场内基金 / 场外基金 / A股 / B股 / 北交所 / 可转债）及其**交易所（沪 SH / 深 SZ / 京 BJ）**&#x4E0E;**细分类型**（ETF / LOF / 封闭式 / REITs / 货币ETF / 跨境ETF / 黄金ETF / 债券ETF / 科创板ETF；或 沪市主板 / 科创板 / 深市主板 / 创业板 / 北交所）。
>
> 数据来源：
>
> - 小熊同学（autostock.cn）`/fund/all` 接口（公募基金全量 27,339 只，含场外）
> - 小熊同学（autostock.cn）`/stock/all` 接口（证券全量 8,373 只，含 A股 / 基金 / 可转债 / B股 / 北交所）
> - 互联网核实：AKShare（东方财富 / 同花顺榜单）、上交所 / 深交所 / 北交所官网、证监会信披平台、证券时报 / 和讯 / 东方财富等公开资料
>
> 生成 / 修订日期：2026-08-18 初版；2026-08-19 修订（新增 A股、可转债 分析 + 修正 场内基金 180xxx 段；补充 **000012 同名碰撞** 与 **404xxx 老三板/北交所混淆** 两类特殊情形处理；另 2026-08-19 修订：**501/505 段升为纯净场内段 + `联接LOF` 特例 + 已退市基金按精确 code 不入库**）

---

## 0. 方法论概览

三类资产的判定**难度与依据完全不同**，故分别建模：

| 资产大类     | 判定依据                                | 难度              | 交易所来源      |
| -------- | ----------------------------------- | --------------- | ---------- |
| **场内基金** | 代码段（纯净/混合）+ **名称标记**（ETF/LOF/REIT…） | 高（OTC 与场内共用代码段） | 代码首位 + 前3位 |
| **A股股票** | 仅代码前缀（前缀即含板块信息）                     | 低（规则稳定、无歧义）     | 代码前缀       |
| **可转债**  | 代码前缀（与 A股/基金 不重叠）+ 名称"转债"佐证         | 低（前缀即权威）        | 代码前缀       |

统一入口先按代码前缀**路由**：可转债（110/113/123/127/128）→ 场内基金（5/15/16/18 段）→ A股/B股/北交所（其余 6 位数字）。参考实现见 `dev-scripts/classify_rules.py` 的函数 `classify_security`（统一）、`classify`（场内基金）、`classify_astock`（A股）、`classify_convertible`（可转债）。

## 第 1 部分：场内基金（交易所 + 资产类型）

### 1.1 数据来源

小熊同学公开 API（`https://api.autostock.cn/v1`）的专用 `/etf/all`、`/lof/all` 端点当前返回 `500`（未公开），但其 `/fund/all` 可用，返回**全市场公募基金**（共 27,339 只，含场外）。

场内基金（上市段）对应代码段为 **沪市 `5xxxxx`、深市 `15xxxxx / 16xxxxx / 18xxxxx`**。据此从 `/fund/all` 筛选出 **2,744** 只候选，作为本部分规则的输入「全部数据」。

### 1.2 关键事实与踩坑（决定规则形态）

1. **OTC 与场内共用代码段（最核心难点）**。同一代码前缀内既可能有场内基金、也可能有场外基金：
   - `519001` 是**场外**混基，但 `519888 添富快线` 是**场内货币ETF**；
   - `560002 益民红利成长混合`、`510080 长盛全债`、`150005 银河银富货币A` 均为**场外**，却占用了 `56/510/150` 等"上市段"代码；
   - 因此**不能仅凭代码前缀判定"是否场内"**，必须叠加「专属子段 ∪ 名称标记」双重判定。
2. **`519xxx` 场内仅限货币ETF**（添富快线/财富宝等），其余 `519xxx` 多为场外。
3. **`510xxx` 含场外债基/混基**（`510080/510081`），故 `510` 不可作纯净 ETF 段，需名称含 `ETF` 才判场内。
4. **`联接`基金 = 场外**（即使名称带 `(LOF)`，如 `160119 南方中证500ETF联接(LOF)A`），须无条件判场外。
5. **`定开`（定期开放）≠ 上市**，`506000 南方科创板3年定开混合` 为场外，不能当场内。
6. **REITs 名称常写 `REIT`（非 `REITs`）**，如 `508000 华安张江产业园REIT`，标记词须含 `REIT`。
7. **LOF 名称常缺 `(LOF)` 后缀**（如 `166002 中欧新趋势混合` 实为 LOF），须靠代码段 `160-169` 兜底判场内。
8. **深市 `180xxx` 段为混合型（本轮修正）**：`1800xx`（如 `180001 银华优势企业混合`、`180008 银华货币A`）是**场外基金**，仅 `1801xx–1808xx` 与 `181001` 等才是**场内 REITs**。故 `180` 不能当作纯净 REITs 段，改用「名称 `REIT`/基础设施 标记」或「`180` + 第4位 ∈ 1-9」识别。

### 1.3 代码前缀 / 名称 → 交易所 + 资产类型 对应关系

**交易所判定（仅看代码前缀）**

| 代码前缀                              | 交易所             | 说明                                      |
| --------------------------------- | --------------- | --------------------------------------- |
| `5xxxxx`                          | **上交所（沪 SH）**   | A股场内基金沪市段                               |
| `15xxxxx` / `16xxxxx` / `18xxxxx` | **深交所（深 SZ）**   | A股场内基金深市段                               |
| `8xxxxx` / `4xxxxx`               | 北交所 / 老三板（京 BJ） | 均非场内基金；`4xxxxx` 实为老三板/全国股转，非北交所（见 §2.5） |
| `0/2/3/6/9xxxxx` 及未列段             | —               | 股票 / B股 / 可转债 / 场外基金等，非场内基金             |

**「是否场内」判定（去 OTC 噪声）**

`listed = 落在【纯净场内子段】 OR 名称含【场内标记】`，否则判场外。

- **纯净场内子段**（代码段本身即专属场内，无需名称佐证）：
  - 沪：`511 512 513 515 516 517 518 520 526 551 561 562 563 588 589 501 502 505 508`
    （`501`/`505` 于 2026-08-19 由混合段升为纯净场内段：`501`=LOF 上市段、`505`=原封基段，
    经 `/fund/all` 实测段内全为场内基金；`502`=LOF/指数段）
  - 深：`158 159 160 161 162 163 164 165 166 167 168 169`（注：`180-184` 已移出纯净段，详见 1.2.8）
- **混合子段**（同段内 OTC/场内共存，必须靠名称标记）：

### 1.4 判定决策树（文字版）

```
输入 (code, name)
  │
  ├─ 非 6 位数字 → 非基金代码
  ├─ 前缀 5 → 沪；15/16/18 → 深；8/4 → 北交所(非场内基金)；其他 → 非场内基金段

  ├─ 名称含"联接" 且不含"LOF" → 场外基金（结束；"联接LOF"如 160119 放行为场内）
  │
  ├─ 落在【纯净场内子段】？ ── 是 ──┐
  │                              │
  ├─ 名称含 场内标记(ETF/LOF/REIT/...)？ ── 是 ─┤
  │                                      │
  ├─ 519xxx 且含货币名？ ── 是 ──────────┤
  │                                      ↓

  │                                      │
```

### 2.5 特殊情形：同名碰撞（000012）与 老三板/北交所 混淆（404xxx）

#### (1) 同名碰撞：`000012` = 南玻A（A股）vs 国债指数（指数）

小熊同学 `/stock/all` 接口中，**同一 6 位代码 `000012` 对应两只不同证券**：

- `sz000012 南  玻Ａ` —— 深交所主板 **A股 股票**（中国南玻集团，深交所上市）；
- `sh000012 国债指数` —— 上交所 **指数**（上证国债指数，中证指数公司编制）。

**根因**：`000xxx` 段在深交所是主板 A股 股票段，但在上交所是**指数代码段**（上证指数 `sh000001`、沪深300 `sh000300`、中证500 `sh000905`、国债指数 `sh000012` 等）。若无交易所区分，仅凭 6 位代码会把指数误判为股票。

**解法**：优先解析接口代码自带的 `sh/sz/bj` 前缀（权威交易所信号）：

- `sz` + `000012` → 深市主板 A股（南玻A）；
- `sh` + `000012` → 上交所/中证指数（国债指数）。  
  指数识别规则：`sh` + `000\d{3}` → 上交所/中证指数；`sz` + `399\d{3}` → 深交所指数（名称含"指数/国债/企债/…"作兜底）。**不带前缀的裸 `000012` 默认按 A股（南玻A）处理**，仅当名称显含指数关键词时才归指数。

> 核实：上交所官网 `csindex.com.cn` 确认 国债指数 代码 `000012`、样本为沪市国债；南玻A 公告（证券代码 `000012`、200012 南玻B）确认其为深交所主板 A股。

#### (2) `4xxxxx` 易与北交所混淆：实为老三板/全国股转（非北交所）

用户指出 `404001`–`404005` 等是**退市公司证券**（含退市股票/转债），其 `4xxxxx` 代码段**极易与北交所**（`920`/`8xxxxx`）混淆。

**根因（据北交所/全国股转《证券代码编制指引》）**：

- `400xxx` = 两网及退市公司 **A股**（全国中小企业股份转让系统"老三板"）；
- `420xxx` = 退市公司 **B股**；
- 其余 `4xxxxx`（如 `43xxxx` 老新三板）= 全国股转系统，**整体非北交所**。  
  而北交所正式代码为 `920xxx`（新段）+ `8xxxxx`（精选层平移），**不含 `4xxxxx`**。

**解法**：将 `4xxxxx` **整体从北交所剥离**，单列"老三板/全国股转"：

- `920xxx` / `8xxxxx` → 北交所/新三板（exchange=BJ）；
- `400xxx` → 老三板(退市A股)；`420xxx` → 老三板(退市B股)；其余 `4xxxxx` → 新三板/老三板（exchange=None，非 BJ）。

> 核实：新浪财经/叩富网/全国股转官网一致确认 `400` 开头=老三板退市A股、`420`=老三板退市B股、`4` 开头整体属三板市场（已从主板退市），与北交所 `920/83/87/88` 明确区分。

## 第 4 部分：统一判定流程与参考实现

### 4.1 统一路由决策树

```
输入 (code, name)
  │
  ├─ 非 6 位数字 → 非标准代码
  │
  ├─ 前缀 110/113/123/127/128 → 【可转债】（SH/SZ）
  │
  ├─ 前缀 5 / 15 / 16 / 18 → 【基金】分支
  │     ├─ 纯净子段 或 名称含 ETF/LOF/REIT… → 场内基金（细分 ETF/LOF/REITs/…）
  │     └─ 否则 → 场外基金
  │
  ├─ 指数（需 sh/sz 前缀辅助，解决 000012 同名碰撞）
  │     ├─ sh + 000xxx → 上交所/中证指数
  │     └─ sz + 399xxx → 深交所指数
  │
  └─ 其余 6 位 → 【股票】分支
        ├─ 600/601/603/605 → 沪市主板(A股)
        ├─ 688            → 科创板(A股)
        ├─ 000/001        → 深市主板(A股)
        ├─ 002/003        → 深市主板原中小板(A股)
        ├─ 300/301        → 创业板(A股)
        ├─ 920 / 8        → 北交所/新三板(A股)
        ├─ 4 (4xxxxx)     → 老三板/全国股转(非北交所，见 §2.5)
        ├─ 900            → 沪市B股(非A股)
        └─ 200            → 深市B股(非A股)
```

### 4.2 Python 参考实现（摘要，`dev-scripts/classify_rules.py`）

核心函数：`classify_security(code, name)`（统一入口，返回 `{asset_class, exchange, sub_type}`）、`classify(code, name)`（场内基金）、`classify_astock(code)`（A股）、`classify_convertible(code, name)`（可转债）。

```python
import re
SH, SZ, BJ = "SH", "SZ", "BJ"

# —— 场内基金：纯净子段 ——
SH_PURE = {"511","512","513","515","516","517","518","520","526","551",
           "561","562","563","588","589","501","502","505","508"}
SZ_PURE = {"158","159","160","161","162","163","164","165","166","167","168","169"}
# 注：深 180-184 已移出纯净段（1800xx 为 OTC）；沪 501/505 于 2026-08-19 由混合段升为纯净场内
SH_MIXED = {"500","510","519","530","550","560","570","580","590"}
SZ_MIXED = {"150","151"}
NAME_MARKET_MARKERS = ("ETF","LOF","(LOF)","REIT","REITs","基础设施","封闭")
OTC_NAME_MARKERS   = ("联接",)
CURRENCY_NAME_KW   = ("货币","现金","保证金","日利","添益","快线","财富宝")

def classify(code, name=""):
    """场内基金 交易所 + 资产类型（详见文档第1部分，含 180xxx 修正）。"""
    ...  # 实现见 classify_rules.py

def _parse_raw(raw_code):
    """小熊同学代码形如 sh000012/sz301141/bj920020，前缀即权威交易所。"""
    m = re.fullmatch(r"(sh|sz|bj)(\d{6})", raw_code.strip().lower())
    if m:
        return {"sh":SH,"sz":SZ,"bj":BJ}[m.group(1)], m.group(2)
    return None, raw_code.strip()

INDEX_NAME_KW = ("指数","国债","企债","公司债","信用债","综指","成指","债指")
def _classify_index(code, ex_hint, name):
    if ex_hint==SH and re.fullmatch(r"000\d{3}", code):
        return {"asset_class":"指数","exchange":SH,"sub_type":"上交所/中证指数"}
    if ex_hint==SZ and re.fullmatch(r"399\d{3}", code):
        return {"asset_class":"指数","exchange":SZ,"sub_type":"深交所指数"}
    if name and any(k in name for k in INDEX_NAME_KW):
        if re.fullmatch(r"000\d{3}", code):
            return {"asset_class":"指数","exchange":ex_hint or SH,"sub_type":"上交所/中证指数"}
        if re.fullmatch(r"399\d{3}", code):
            return {"asset_class":"指数","exchange":ex_hint or SZ,"sub_type":"深交所指数"}
    return None

def classify_astock(code):
    """A股 交易所 + 板块（仅看前缀）。4xxxxx=老三板/全国股转，非北交所。"""
    code=(code or "").strip()
    if not re.fullmatch(r"\d{6}", code): return {"exchange":None,"board":None,"asset_class":"非6位数字代码"}
    p=code[:3]; p1=code[0]
    if p in ("600","601","603","605"): return {"exchange":SH,"board":"沪市主板","asset_class":"A股"}
    if p=="688":                       return {"exchange":SH,"board":"科创板","asset_class":"A股"}
    if p in ("000","001"):            return {"exchange":SZ,"board":"深市主板","asset_class":"A股"}
    if p in ("002","003"):            return {"exchange":SZ,"board":"深市主板(原中小板)","asset_class":"A股"}
    if p in ("300","301"):            return {"exchange":SZ,"board":"创业板","asset_class":"A股"}
    if p=="920" or p1=="8":           return {"exchange":BJ,"board":"北交所/新三板","asset_class":"A股"}
    if p1=="4":                       # 老三板/全国股转，非北交所
        if p=="400": return {"exchange":None,"board":"老三板(退市A股)","asset_class":"老三板/全国股转"}
        if p=="420": return {"exchange":None,"board":"老三板(退市B股)","asset_class":"老三板/全国股转"}
        return {"exchange":None,"board":"新三板/老三板(全国股转)","asset_class":"老三板/全国股转"}
    if p=="900":                      return {"exchange":SH,"board":"沪市B股","asset_class":"B股"}
    if p=="200":                      return {"exchange":SZ,"board":"深市B股","asset_class":"B股"}
    return {"exchange":None,"board":None,"asset_class":"其他/非上市股票代码"}

CB_SH_PREFIX=("110","113"); CB_SZ_PREFIX=("123","127","128")
def classify_convertible(code, name=""):
    """可转债 交易所（代码前缀权威，名称含'转债'佐证）。"""
    code=(code or "").strip(); name=(name or "").strip()
    if not re.fullmatch(r"\d{6}", code): return {"exchange":None,"asset_class":None,"is_cb":False}
    p=code[:3]
    if p in CB_SH_PREFIX: return {"exchange":SH,"asset_class":"可转债","is_cb":True}
    if p in CB_SZ_PREFIX: return {"exchange":SZ,"asset_class":"可转债","is_cb":True}
    if p in ("118","132"): return {"exchange":SH,"asset_class":"可交债(EB)","is_cb":False}
    if p=="120":           return {"exchange":SZ,"asset_class":"可交债(EB)","is_cb":False}
    return {"exchange":None,"asset_class":None,"is_cb":False}

def classify_security(raw_code, name=""):
    """统一入口：解析 sh/sz/bj 前缀 → 可转债 → 场内基金 → 指数 → A股/B股/北交所/老三板。"""
    ex_hint, code = _parse_raw(raw_code)
    name=(name or "").strip()
    if not re.fullmatch(r"\d{6}", code): return {"asset_class":"非6位数字代码","exchange":None,"sub_type":None}
    p=code[:3]; p1=code[0]
    cb=classify_convertible(code,name)
    if cb["is_cb"]: return {"asset_class":"可转债","exchange":cb["exchange"],"sub_type":cb["asset_class"]}
    if p1=="5" or p[:2] in ("15","16","18"):
        f=classify(code,name)
        return {"asset_class":"场内基金" if f["listed"] else "场外基金",
                "exchange":f["exchange"], "sub_type":f["asset_type"]}
    idx=_classify_index(code, ex_hint, name)   # 解决 000012 同名碰撞
    if idx: return idx
    a=classify_astock(code)
    return {"asset_class":a["asset_class"],"exchange":a["exchange"],"sub_type":a["board"]}
```

## 第 5 部分：局限与说明

1. **场内基金 OTC/场内碰撞**：`519/510/550/150` 等段场内场外共存，须依赖名称标记；`519xxx` 仅货币ETF 特例、`联接` 一律场外（**`联接LOF` 例外，为场内**）、`定开` 一律场外、`REITs` 名称常写 `REIT`。已退市基金以精确 code 集合 `DELISTED_FUND_CODES` 拦截不入库。建议生产环境接基金公司/交易所官方分类字段以 100% 细分。
2. **LOF/REITs/封基 全量金标准缺失**：东方财富 `fund_lof_spot_em` 等接口在沙箱被限流，未能下载完整清单；该分支以「名称+代码」自洽 + 代表性证券互联网核实，召回 0 漏判，建议以完整榜单（东财/集思录）再回归一轮。
3. **A股/可转债 规则极稳定**：代码前缀即权威，互联网核实与接口数据 100% 吻合，无需名称即可判定；名称仅作佐证（如可转债"转债"）。
4. **北交所 vs 老三板**：`920`/`8xxxxx` 归北交所/新三板；`4xxxxx` 整体属全国股转/老三板（`400`=退市A股、`420`=退市B股），**不是北交所**，须单列排除（详见 §2.5）。
5. **指数与 A股 同名碰撞（`000012` 等）**：上交所 `000xxx` 段为指数代码（国债指数/上证指数/沪深300…），深交所 `000xxx` 为主板 A股（南玻A）。仅凭 6 位代码会误判，须**解析接口自带的 `sh/sz/bj` 前缀**作为权威交易所信号（见 §2.5）。生产环境若只拿到裸 6 位代码，可用名称含"指数/国债/企债/…"兜底识别指数。
6. **分析过程产物**（`dev-scripts/` 下 `fund_all.json`、`stock_all.json`、各 `validate*.py`）为可复现脚本与数据，规则本身以本文映射表 + 第 4.2 节实现为准；接入系统时可把 `classify_security()` 直接移植为服务层函数。
