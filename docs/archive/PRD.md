## 1. 产品概述

### 1.1 基本信息

| 项目 | 内容 |
|------|------|
| 产品名称 | `investment_return_tracker`（投资收益统计系统） |
| 一句话定位 | 基于 XIRR 算法的多端投资组合收益与净值追踪平台 |
| 目标用户 | 个人投资者、小型机构投资者 |
| 核心价值 | 精确计算真实年化收益率（XIRR），每日记录累计净值与当年净值，提供年/月/周/日多维度可视化分析 |

| 前端技术 | Web 版 + HarmonyOS 最新版 APP（ArkTS + ArkUI） |

### 1.2 原始需求复述

1. 通过输入存入取出金额、期末资产额
2. 使用 XIRR 计算投资收益（存入=负、取出=正、当日资产额=正终值），记录每日的 XIRR，可以通过年月周日查询
3. 计算出净值，分为累计净值和当年净值，并且要记录出每日的累计净值和当年净值，可以通过年月周日查询
4. 所有年月周日查询都做成可视化
5. 后端使用 PostgreSQL 保存数据
6. 前端使用 HarmonyOS 最新版 APP 和 Web 版本，使用 Git 管理代码

**做什么（In Scope）**:
- 单用户投资组合的现金流录入（存入/取出/资产快照）

- 累计净值与当年净值的每日计算与记录
- 年/月/周/日四维度查询与可视化展示
- Web 端与 HarmonyOS APP 端双端覆盖，共用后端 API
- 数据导入导出（CSV/Excel）
- 自动获取证券/基金行情估值（如通过公开 API 获取最新净值/价格），作为持有资产估值的自动化手段。具体实现方式（数据源、更新频率、缓存策略）待架构设计

- ❌ 多币种汇率自动换算（v1 单币种，多币种列入待确认）
- ❌ 社交/社区功能
- ❌ 税务计算与合规报表

## 3. 核心概念定义（CRITICAL）

> 本章是整个项目的基础，XIRR 与净值的计算口径必须严谨无歧义。以下定义参照公募基金净值计算惯例。

### 3.1 XIRR（扩展内部收益率）

**定义**：XIRR（Extended Internal Rate of Return）是针对**非定期（不规则间隔）现金流**计算年化收益率的算法。它求解使所有现金流净现值（NPV）为零的年化折现率 r：

$$\sum_{i=0}^{n} \frac{CF_i}{(1+r)^{(d_i - d_0)/365}} = 0$$

其中 CF_i 为第 i 笔现金流，d_i 为对应日期，d_0 为第一笔现金流日期。

**输入数据约定**：

| 数据类型 | 现金流方向 | 符号 | 说明 |
|----------|-----------|------|------|
| 存入（投入资金） | 流出 | 负值（-金额） | 资金从投资者账户流出进入投资 |
| 取出（收回资金） | 流入 | 正值（+金额） | 资金从投资收回进入投资者账户 |
| 当日资产额 | 终值 | 正值（+金额） | 当日持仓的市值估值，作为 XIRR 的终值（terminal value） |

**与 IRR / CAGR 的区别**：

| 指标 | 现金流要求 | 时间假设 | 适用场景 |
|------|-----------|---------|---------|
| IRR | 定期（等间隔） | 假设各期等长 | 定期定额投资 |
| **XIRR** | **非定期（任意日期）** | **按实际天数/365 折现** | **本项目：不规则存取** |
| CAGR | 仅需首末两值 | 忽略中间现金流 | 简单首末对比，不反映追加/赎回影响 |

**结论**：本项目采用 XIRR，因为它能精确处理投资者任意日期存取的真实场景，是衡量个人投资真实年化收益的金标准。

### 3.2 每日 XIRR

**定义**：指从**第一笔存入日**起，到**当日**为止的**累计 XIRR**。

**计算口径（推荐）**：
- 现金流序列 = [第一笔存入日 ~ 当日的所有存入/取出记录] + [当日资产额作为终值]
- 即：将当日持仓总市值视为一笔"当日发生的正现金流"，与历史所有存入取出现金流一起代入 XIRR 公式求解
- 每个交易日（有资产快照的日子）计算一次，得到一个 XIRR 值，形成时间序列

**为什么选累计口径而非滚动口径**：

| 方案 | 定义 | 优点 | 缺点 |
|------|------|------|------|
| ✅ **累计 XIRR**（推荐） | 从第一笔存入到当日的整体年化收益 | 反映真实总回报，与基金披露口径一致，跨年/月/周/日查询均可纵向对比 | 长期后会趋稳，对近期变化不够敏感 |
| 滚动 XIRR | 过去 N 天（如 365 天）窗口的 XIRR | 反映近期表现 | 窗口初期数据不足，口径主观，跨期不可比 |

**推荐理由**：累计 XIRR 与公募基金/私募基金披露的年化收益率口径一致，用户认知成本低；通过年/月/周/日查询可观察该累计值随时间的演变趋势，已能满足分析需求。滚动 XIRR 列入 P2 增强。

**查询维度说明**：按年/月/周/日查询时，展示的是该时间范围内**每日累计 XIRR 值的序列**。例如"按月查询 2025 年 3 月"，展示 3 月每一天的累计 XIRR 折线图。

### 3.3 累计净值

**定义**：类比公募基金累计净值，反映投资组合从成立日（第一笔存入日）起的整体净值增长。

**计算方法——单位份额法（推荐）**：

采用公募基金标准的"份额-净值"模型：

1. **成立日（第一笔存入日）**：单位净值 = 1.0000，初始份额 = 存入金额 / 1.0000 = 存入金额
2. **每日估值流程**（日终处理）：
   - Step 1：根据当日资产快照（期末总额，含当日存入/取出）、当日存入/取出金额和上日末份额，计算当日单位净值：
     $$当日单位净值 = \frac{当日资产总额（快照） − 当日存入总额 + 当日取出总额}{上日末总份额}$$
   - Step 2：按当日单位净值处理当日存入/取出（申赎）：
     - 存入新增份额 = 存入金额 / 当日单位净值
     - 取出赎回份额 = 取出金额 / 当日单位净值
     - 当日末总份额 = 上日末份额 + 新增份额 - 赎回份额
3. **累计净值 = 单位净值**（本项目 v1 不涉及分红，故累计净值即单位净值）

**基准日**：第一笔存入日，累计净值 = 1.0000

**示例**：
- Day 1：存入 10000 → 份额 10000，净值 1.0000，资产 10000
- Day 30：存入 6000 后账户期末总额 18000 → 申赎前资产 = 18000 − 6000 = 12000 → 净值 = 12000/10000 = 1.2000 → 新增份额 = 6000/1.2000 = 5000，总份额 15000
- Day 60：期末资产快照 16500 → 净值 = 16500/15000 = 1.1000

### 3.4 当年净值

**定义**：反映本年度（自然年）内的净值增长，每年 1 月 1 日重置基准。

**计算公式**：

$$当年净值_t = \frac{累计净值_t}{累计净值_{上年最后一个交易日}}$$

**规则**：
- 每年 1 月 1 日（或当年第一个交易日），当年净值 = 1.0000
- 当年净值反映本年度内的收益率：当年净值 - 1 = 当年收益率
- 跨年对比时，各年度起点统一为 1.0000，便于横向比较年度表现
- 上年最后一个交易日的累计净值作为本年度基准值，记录为 `base_cumulative_nav`

**与累计净值的关系**：
- 累计净值 = 整体回报（从成立日起）
- 当年净值 = 年内回报（从本年 1 月 1 日起）
- 两者互补：累计净值看长期，当年净值看年度

### 3.5 存入 / 取出 / 期末资产额

| 数据类型 | 含义 | 录入粒度 | 符号约定 |
|----------|------|---------|---------|
| 存入 | 投入资金购买资产，资金流出 | 按笔录入（日期 + 金额） | 现金流为负 |
| 取出 | 取出资产收回资金，资金流入 | 按笔录入（日期 + 金额） | 现金流为正 |
| 期末资产额（资产快照） | 当日持仓的总市值估值 | 按日录入（日期 + 总市值） | XIRR 终值为正 |

**录入规则**：
- 存入/取出：一笔交易一条记录，含交易日期、方向、金额、备注
- 资产快照：每个交易日一条，记录当日总资产市值。**资产快照是触发当日净值与 XIRR 计算的前提**——没有当日快照则不计算当日净值/XIRR
- 同一天可有多笔存入/取出，但只有一个资产快照

## 5. 数据录入与计算流程

### 5.1 交易录入流程

```
用户操作                    系统处理
────────                    ────────
选择交易类型(存入/取出)  →   记录方向
输入交易日期             →   校验: 非未来日期
输入交易金额             →   校验: 金额 > 0
输入备注(可选)           →   存储
提交                    →   ① 保存交易记录
                           ② 若当日已有资产快照 → 触发当日重算(净值/XIRR)
                           ③ 若当日无快照 → 等待快照录入后计算
```

### 5.2 资产快照录入流程

```
用户操作                    系统处理
────────                    ────────
选择日期                →   校验: 非未来日期
输入当日资产总额        →   校验: 金额 > 0
提交                    →   ① 保存/更新当日快照
                           ② 触发当日净值计算(份额法)
                           ③ 触发当日 XIRR 计算
                           ④ 更新当日净值/XIRR 时间序列
```

### 5.3 每日 XIRR 计算触发机制

**推荐方案：实时计算 + 日终批处理**

| 触发时机 | 行为 |
|---------|------|
| 录入/修改资产快照时 | 实时计算当日 XIRR（现金流序列=历史所有交易+当日资产额终值） |
| 录入/修改交易时 | 若当日已有快照，实时重算当日 XIRR |
| 日终批处理（可选） | 遍历当日所有用户，确保当日计算完成（兜底） |
| 历史数据修改 | 从修改日起到最新日期，批量重算受影响日期的 XIRR |

**XIRR 算法实现要求**：
- 使用牛顿迭代法求解（收敛快），初始猜测值 r₀ = 0.1（10%）
- 最大迭代 100 次，收敛阈值 |NPV| < 1e-7
- 特殊情况处理：全为同号现金流（纯存入无取出无终值）时返回 null，提示"数据不足"
- 后端实现，通过 API 返回结果

### 5.4 每日净值计算逻辑

采用 3.3 节单位份额法，日终处理流程：

```
对于每个有资产快照的交易日 t：
  1. 读取 t 日资产快照金额 asset_t（**期末账户总额，含当日存入/取出**）
  2. 读取 t-1 日末总份额 shares_{t-1}
     （若 t 为成立日，份额=首笔存入金额，净值=1.0）
  3. 计算当日申赎前净值：
     当日存入总额 buy_t = Σ(当日存入类型交易金额)
     当日取出总额 sell_t = Σ(当日取出类型交易金额)
     nav_t = (asset_t − buy_t + sell_t) / shares_{t-1}
  4. 处理当日申赎:
     存入 b → 新增份额 = b / nav_t
     取出 s → 赎回份额 = s / nav_t
     shares_t = shares_{t-1} + b/nav_t - s/nav_t
  5. 累计净值 cumulative_nav_t = nav_t
  6. 当年净值:
     若 t 为当年首个交易日 → year_nav_t = 1.0000, base = cumulative_nav_{t-1}
     否则 → year_nav_t = cumulative_nav_t / base
  7. 存储当日: nav_t, cumulative_nav_t, year_nav_t, shares_t
```

### 5.5 数据校验规则

| 校验项 | 规则 | 错误提示 |
|--------|------|---------|
| 交易金额 | 必须 > 0 | "金额必须大于 0" |
| 交易日期 | 不可晚于今天 | "日期不能为未来日期" |

## 附录 A：XIRR 计算伪代码

```
function calculateXIRR(cashflows):  // cashflows = [{date, amount}, ...]
    // amount: 存入为负，取出为正，终值（当日资产额）为正
    if cashflows.length < 2: return null
    if all same sign: return null  // 数据不足

    rate = 0.1  // 初始猜测 10%
    maxIter = 100
    tolerance = 1e-7

    for i in 0..maxIter:
        npv = sum(cf.amount / (1+rate)^((cf.date - cashflows[0].date)/365))
        dnpv = sum(-cf.amount * (cf.date - cashflows[0].date)/365
                   / (1+rate)^((cf.date - cashflows[0].date)/365 + 1))
        if abs(npv) < tolerance: return rate
        if dnpv == 0: break
        rate = rate - npv / dnpv
        if rate <= -1: rate = -0.999  // 防止溢出

    return rate  // 年化收益率
```

## 附录 B：净值计算伪代码

```
function calculateDailyNav(date, assetSnapshot, transactions, prevRecord):
    if prevRecord is null:  // 成立日
        firstBuy = transactions.filter(t => t.date == date && t.type == 'BUY')
        shares = sum(firstBuy.amount)
        nav = 1.0000
        cumNav = 1.0000
        yearNav = 1.0000
        base = 1.0000
    else:
        shares = prevRecord.shares
        // 当日存入/取出金额
        buyAmount = sum(transactions.filter(BUY).amount)
        sellAmount = sum(transactions.filter(SELL).amount)
        // 期末口径：assetSnapshot 含当日进出，需还原为申赎前资产再计算净值
        nav = (assetSnapshot - buyAmount + sellAmount) / shares
        cumNav = nav
        if isYearFirstTradingDay(date):
            base = prevRecord.cumNav  // 上年末累计净值为基准
            yearNav = 1.0000
        else:
            yearNav = cumNav / base

        // 处理当日申赎
        shares += buyAmount / nav - sellAmount / nav

    return {date, nav, cumNav, yearNav, shares, base}
```
