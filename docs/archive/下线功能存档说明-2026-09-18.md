## 4. 重新集成指南（若日后需恢复某功能）

1. **仅恢复某个归档文件**（如回补引擎）：
   ```bash
   git checkout archive-discontinued -- backend/app/services/market_price_backfill_engine.py
   # 等价：git checkout 056a898 -- <path>
   ```
2. **恢复被「裁剪」的共享文件里的功能片段**（如 `market_daily_price_sync` 的钩子）——这些文件**不在**
   归档分支上，用 `056a898` 取原始版本：
   ```bash
   git show 056a898:backend/app/services/market_daily_price_sync.py   # 对照原始版本
   ```
   再手动把相关钩子/import 移植回当前 `main`。
3. **迁移**：回补相关的 8 个建列迁移需重新引入并重接链；`0028` 的 drop 需回退或撤销。
4. **前端**：曲线图组件与 API 层可从归档分支取回，再补 `api/types.ts` / `constants.ts` 等共享文件的片段。
5. 集成后务必重跑：`uv run pytest`（后端）、`pnpm lint` + 相关 vitest（前端）。
