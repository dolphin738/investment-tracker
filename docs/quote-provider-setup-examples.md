## 三、新增接口 2：所有股票（/stock/all）

| 表单字段       | 填写值                                    | 取值依据   |
| ---------- | -------------------------------------- | ------ |
| 接口分类       | 下拉选已有分类（如「A股行情」）                       | 纯外键    |
| 名称         | `所有股票`                                 | 文档接口标题 |
| 调用路径       | `/stock/all`                           | 文档路径   |
| HTTP 方法    | GET                                    | 文档方法   |
| 参数模板(JSON) | `{}`（全量）或 `{"keyWord":"string"}`（模糊查）  | 见下方说明  |
| 描述         | 选填，如 `小熊同学所有股票列表（支持 keyWord 代码/名称模糊查）` | —      |
| 启用         | 开（默认）                                  | —      |

请求参数（Query）
- `keyWord`（string，**非必填**）：支持代码和名称模糊查询。

> 参数模板二选一（一个接口一份模板，不能两种同时塞）：
> - 填 `{}` → 系统调用 `GET /stock/all`（不带 Query），返回全部股票。推荐，因「所有股票」本职即全量。
> - 填 `{"keyWord":"string"}` → 系统调用 `GET /stock/all?keyWord=string` 做筛选。
> 若需同一来源同时支持两种用法：可建两个接口（同路径 `/stock/all`，靠模板区分用途）。

响应（200）
```json
{ "code": 0, "message": "", "traceId": "", "data": [[""]], "meta": {} }
```

## 四、关键拆分提醒

1. **Base URL 与路径分离**：`https://api.autostock.cn/v1` 进「数据来源」，接口只存 `/stock`、`/stock/all`。运行时系统拼接为 `https://api.autostock.cn/v1/stock?code=...`。
2. **同一来源多接口**：小熊同学来源下可挂多个接口（`/stock`、`/stock/all` …），无需重复建来源。
3. **信封一致**：文档响应的 `code/message/data` 结构与本系统后端契约吻合，无需额外适配。

---

## 五、参数模板填写注意事项

- 必须是**合法 JSON**，且用**半角**字符：花括号 `{}` 与双引号 `""` 都用英文半角。中文输入法误输全角 `｛｝` 或全角引号会被校验拦截（报「参数模板不是合法 JSON」）。
- 本系统已对「参数模板」输入框做容错：自动把全角花括号/引号、BOM、零宽空格归一为半角（见 `web/src/features/admin/quote-interface-dialog.tsx` 的 `normalizeJsonInput`），但养成半角输入习惯最稳妥。
- 不要将两个 JSON 拼在一起（如 `{} {"keyWord":"string"}`），那不是合法 JSON。

### 6.1 SDK 模式通用填写规则

AKShare 是 Python SDK 库，接入方式选 **SDK**（不是 HTTPS）。

| 表单字段       | 通用填写                               | 说明                                                        |
| ---------- | ---------------------------------- | --------------------------------------------------------- |
| 接入方式       | **SDK（如 akshare）**                 | 非 HTTPS；SDK 模式**无「API 基础地址」字段**，别填 URL                    |
| SDK 名称     | **`akshare`**                      | Python 包名，后端按 `config.sdk_name` 识别并调用                     |
| 调用路径       | 填**函数名**（如 `stock_zh_a_spot_em`）   | SDK 模式填函数名，**不是** http 路径（对话框 placeholder 已注明「SDK 时为函数名」） |
| HTTP 方法    | **不设置**                            | SDK 函数无 HTTP 语义，勿选 GET                                    |
| 参数模板(JSON) | 无参填 `{}`；有参填 `{"symbol":"string"}` | 见各接口；已做全角/不可见字符容错                                         |

### 6.2 数据来源组织口径：按提供方分来源

虽然都经 `akshare` 库调用，但**东财与雪球是不同数据提供方**，建议分别建来源（语义清晰、便于「当前/默认」管理与汇总分组）：

- 「东方财富(AKShare)」：承载东财 3 个接口
- 「雪球(AKShare)」：承载雪球 1 个接口
- 两个来源接入方式均为 SDK、SDK 名称均为 `akshare`

> 若后端仅以 `sdk_name=akshare` 路由、且你不愿区分提供方，也可全挂一个 akshare 来源；但「数据来源」概念即「提供方」，分来源更符合业务语义。

### 6.5 易错点总结

1. **接入方式选 SDK**：不要误选 HTTPS；SDK 模式无「API 基础地址」输入框。
2. **调用路径填函数名**：如 `stock_zh_a_spot_em`，不是 `https://quote.eastmoney.com/...`。
3. **HTTP 方法选「不设置」**：SDK 函数无 HTTP 语义，勿选 GET/POST。
4. **参数模板：无参 `{}` / 有参 `{"symbol":"string"}`**：个股接口（A3、B1）`symbol` 必填，填 `{}` 调用时会因缺参报错。
5. **东财 vs 雪球 symbol 格式不同**：东财 `000001`（纯代码）；雪球 `SH601127`（带 `SH`/`SZ` 前缀）。调错格式会失败。
6. **雪球 token 鉴权**：默认 None，实际调用可能需有效 `xq_a_token`；失败时补 `token` 入参。
7. **按提供方分来源**：雪球接口放在新建的「雪球(AKShare)」来源下，**不要挂到「东方财富(AKShare)」**。
8. **同来源多接口**：东财 3 个接口、雪球 1 个接口分别挂在各自来源下，无需为每个接口重建来源。
